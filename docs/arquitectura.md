# Arquitectura SOAP – Clínica SaludTotal

- **RA-01** Persistencia de datos en `storage/pacientes.xml`.
- **RA-02** Contrato WSDL en `public/wsdl/pacientes.wsdl`.
- **RA-03** Servidor SOAP en `public/server/index.php` usando `SoapServer`.
- **RA-04** Cliente en `public/client/Cliente.php` usando `SoapClient`.
- **RA-05** Interfaz HTML/CSS en `public/views/*.php` + `public/assets`.
